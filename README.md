# Расписание МГТУ

Самостоятельный сайт с выбором группы. Первая версия подключает официальные расписания СТ-11—СТ-15. Другие записи каталога пока недоступны для выбора; это тестовая версия для постепенного расширения на весь вуз.

## Установка в новый репозиторий

1. Откройте https://github.com/new.
2. Владелец — ваш аккаунт (например, `zaretsky123`), название — `mgtu-schedule`, видимость — Public. Создайте репозиторий. Сайт не зависит от конкретного аккаунта или названия репозитория.
3. Распакуйте архив и загрузите его содержимое в корень нового репозитория: Add file → Upload files. В корне должен быть `index.html`, а рядом папки `assets`, `scripts`, `university-data`, `.github`. Сохраните структуру папок. Затем Commit changes в ветку `main`.
4. Откройте Settings → Pages. Source: Deploy from a branch; Branch: main; Folder: / (root). Нажмите Save.
5. После успешной публикации откройте ссылку, показанную на странице Pages. Для аккаунта `zaretsky123` и названия `mgtu-schedule`: https://zaretsky123.github.io/mgtu-schedule/.
6. Введите `ст 12`, откройте группу и проверьте Настройки → Подгруппа.

Если при перетаскивании пропустилась скрытая папка `.github`, создайте файл `.github/workflows/update-university.yml` через Add file → Create new file и вставьте текст одноимённого файла из архива. Пустой `.nojekyll` также можно создать через интерфейс GitHub, если загрузка пустого файла не удалась.

Старые репозитории проектов 1 и 2 не требуют изменений. Предыдущий архив предназначался для добавления страницы в проект 2; для этого нового репозитория используйте этот полный комплект.

## Возможности

- Поиск группы во время ввода. Регистр, пробелы и дефисы игнорируются: `ст 12`, `ст12`, `СТ-12` дают одинаковые результаты.
- Поиск по подразделению, сохранение выбранной группы на устройстве.
- Настройка подгруппы: все, первая, вторая. Общие занятия показаны при любом выборе.
- Календарь, свайпы недель и дней, подробности пары, прогресс и заметки.
- Заметки сохраняются в браузере отдельно по группе; синхронизации между устройствами нет.
- Загружается только JSON выбранной группы. В текущем сеансе повторный выбор использует уже загруженные данные.
- При недоступной загрузке используется сохранённая на устройстве версия с предупреждением. Первое открытие требует интернета; это ещё не PWA с автономным запуском приложения.

## Данные и ограничения

Источник: https://local.mkgtu.ru/raspisnew/print.php. Обработчик читает общедоступный HTML; наличие документированного открытого API не подтверждено.

В каталоге 853 записи из меню источника. Среди них повторяющиеся названия, подгруппы и архивные записи — это не подтверждённое количество действующих учебных групп. В комплекте готовы СТ-11, СТ-12, СТ-13, СТ-14, СТ-15. Для остальных подразделений ещё нужно проверить формат и полноту данных, а каталог очистить от устаревших записей.

Официальные данные импортируются без личных исключений и переносов из старого проекта СТ-11. Учебный период пока: 1 сентября — 27 декабря 2026 года. Расписание преподавателей в эту версию не входит.

## Автоматическое обновление

Workflow «Обновление расписания МГТУ» обновляет подключённые группы ежедневно в 05:43 по Москве. В Actions его можно запустить вручную через Run workflow:

- `connected`: уже подключённые группы (по умолчанию);
- `all`: попытка получить расписания всех записей каталога;
- ID через запятую: подключение или обновление выбранных групп, например `3027,3028`.

Получение всего каталога может идти долго и закончиться частичной ошибкой для старых или неподдерживаемых записей. Успешные группы сохраняются. При ошибке существующее расписание не заменяется пустыми данными. Статусы видны в журнале и `university-data/catalogue.json`.

После полного сбора проверьте несколько групп из каждого подразделения. Workflow для нового репозитория ещё не запускался на GitHub: в комплекте подготовлены его код и данные.

## Разработка

Для локального запуска: `python -m http.server 8000` из корня проекта, затем http://localhost:8000/.

Проверка обработчика: `python -m unittest discover -s scripts -p 'test_university.py'`.

Обновление подключённых групп: `python scripts/update_university.py --ready-only`.

Точечное обновление скачанного каталога: `python scripts/update_university.py --cached-catalogue --groups 3027,3028`.

Клиент собран на React. Файлы в `assets` включают существующий собранный интерфейс расписания и новый читаемый модуль выбора группы `university.js`. Для текущей версии установка npm и сборка не требуются.

Проверено локально: обработчик подгрупп, мобильный и настольный интерфейс, выбор групп, сохранение подгруппы и заметок, карточки, свайп дня, резервная загрузка сохранённых данных. При установке в новый репозиторий нужно отдельно проверить публикацию Pages и запуск workflow.

## Настройки и сохранённые группы

Шестерёнка находится справа вверху, кнопка «Сегодня» под ней. Настройки открываются отдельным экраном. В нём доступны подгруппа, компактный вид, пустые пары, индикатор заметок и сведения о проверке расписания.

В сохранённых группах можно добавить расписание, переключить текущую группу, назначить основную (звёздочка) и удалить сохранённую запись. Основная открывается при следующем входе. Подгруппа запоминается отдельно для каждой группы, настройки отображения общие для сайта.

Компактный вид сохраняет время, предмет, аудиторию и преподавателя; раскрытая карточка остаётся полной. Пустые пары показываются до первого занятия и между занятиями; на день без занятий остаётся сообщение «Пар нет». Индикатор появляется для непустой заметки и исчезает после её удаления.

При обновлении существующего сайта из архива настроек загрузите его содержимое в корень того же нового репозитория. В комплекте `index.html`, `README.md` и четыре файла внутри `assets`. После Commit changes дождитесь публикации Pages и перезагрузите сайт.

Поиск преподавателей и экспорт в календарь остаются следующими этапами. Каталог аудиторий не планируется.
